ReportBot: from setup to daily use

The whole journey for the Telegram and web report chatbot on MySQL with Claude, in four phases. Each step matches the numbered steps in the SOP.

SetupRunning Teaching reportsProblem / fix

1. One-time setup

Keys, MySQL, Docker, settings, first start. Red boxes are the problems we actually hit and their fixes.

flowchart TD
  A([Start]) --> B["Step 1: Get keys
Claude API key, BotFather token,
your Telegram ID"]
  B --> C["Step 2: MySQL Workbench
CREATE DATABASE reportbot
CREATE USER reportbot (read-only on ERP)"]
  C --> D["Step 3: Install Docker Desktop
restart laptop, wait for Engine running"]
  D --> E{"docker --version
works?"}
  E -- No --> E1["Add DockerDesktop\resources\bin
to Path, reopen PowerShell"]:::stop
  E1 --> E
  E -- Yes --> F["Step 4: Extract zip to C:\reportbot
put cloudflared.exe in folder"]
  F --> G["Step 5: copy .env.example .env
fill keys, DB URLs, admin ID"]
  G --> H["Step 6: docker compose up -d --build"]
  H --> I{"docker compose ps
STATUS = Up?"}
  I -- "Restarting" --> I1["docker compose logs --tail 40
Access denied: use reportbot user
Unknown DB: create reportbot"]:::stop
  I1 --> J["Fix .env / MySQL
docker compose up -d --force-recreate"]:::stop
  J --> I
  I -- Up --> K["tools.manage init
prints admin web link"]
  K --> L["Test web chat on localhost:8000"]
  L --> M([Setup done]):::setup

2. Go live: public link, Telegram and users

The tunnel gives the laptop an https address so Telegram and outside users can reach it.

flowchart TD
  A([Setup done]) --> B["Step 7: second PowerShell
cloudflared tunnel --url http://localhost:8000"]
  B --> C["Copy https://xxxx.trycloudflare.com
set PUBLIC_BASE_URL in .env"]
  C --> D["docker compose up -d --force-recreate"]
  D --> E["tools.manage set-webhook"]
  E --> F{"ok: True?"}
  F -- "Failed to resolve host" --> F1["Tunnel closed or link wrong
check link/health, wait 1 min"]:::stop
  F1 --> C
  F -- Yes --> G["Telegram: open bot, send /start"]
  G --> H{"Registered?"}
  H -- No --> H1["UPDATE rb_users SET telegram_id
WHERE id = 1"]:::stop
  H1 --> G
  H -- Yes --> I["Add users: tools.manage add-user
admin / manager / viewer"]
  I --> J["Send each person their own web link
or Telegram access"]
  J --> K([Live]):::run

3. Teaching a report

Managers and admins teach a format once; it becomes a /command anyone allowed can run.

flowchart TD
  A(["/teach + description
format, rules, cross-checks"]) --> B["Optional: attach existing
Excel / PDF report"]
  B --> C["Bot asks questions
date column, cancelled status, units"]
  C --> D["Bot explores tables,
writes and runs SQL"]
  D --> E["Preview table + check results"]
  E --> F{"Matches manual report
for 2-3 known dates?"}
  F -- No --> G["Tell bot what is wrong
e.g. remove transfer challans"]:::teach
  G --> D
  F -- Yes --> H["Say save"]
  H --> I(["New command saved
e.g. /daily_dispatch, versioned"]):::teach
  classDef teach fill:#fdf1e3,stroke:#b4691b,color:#4a2a08;

4. Every request and every day

What happens when someone asks a question, and what to do after the laptop restarts.

flowchart TD
  U(["User message
Telegram or web, any of 4 languages"]) --> R{"Registered and active?"}
  R -- No --> X["Bot replies: not registered,
shows ID for admin"]:::stop
  R -- Yes --> S{"Starts with a taught
/command?"}
  S -- Yes --> T["Load report rules,
format and cross-checks"]
  S -- No --> V{"Role allows
free questions?"}
  V -- "Viewer" --> W["Offer list of taught reports"]
  V -- "Manager / admin" --> Y["Find tables, write SQL"]
  T --> Z["Read-only SELECT on venuserp_replica"]
  Y --> Z
  Z --> Q["Run cross-checks"]
  Q --> O["Render: table, Excel, PDF, chart, HTML"]
  O --> P["Save to history"]
  P --> REPLY(["Reply with summary + files"]):::run

  RS(["Laptop restarted"]) --> R1["Open Docker Desktop"]
  R1 --> R2["Start cloudflared, copy NEW link"]
  R2 --> R3["Update PUBLIC_BASE_URL
--force-recreate, set-webhook"]
  R3 --> R4(["Send users new address,
same token"]):::run
